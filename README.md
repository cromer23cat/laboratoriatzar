**Laboratori de l'Atzar** és una aplicació web educativa i interactiva dissenyada per a l'alumnat de **Cicle Superior de Primària** amb l'objectiu d'experimentar i comprendre els conceptes bàsics de la probabilitat i l'atzar de manera pràctica i visual.

---

### Key Features & Design

* **Experiments Simulats:** Permet triar i configurar diferents tipus d'experiències atzaroses (com ara el llançament de monedes o l'extracció de boles de colors d'una urna amb/sense reposició).
* **Configuració Paramètrica:** Permet definir els paràmetres inicials de l'experiment (nombre de boles de cada color, quantitat de monedes, etc.) i triar el nombre d'intents o repeticions a executar (des d'intents individuals fins a simulacions massives).
* **Taula de Freqüències i Dades en Temps Real:** Registra els resultats obtinguts i calcula automàticament:
* **Freqüència Absoluta ($f$):** Nombre de vegades que surt cada resultat.
* **Freqüència Relativa (%):** Percentatge observat a la simulació.
* **Probabilitat Teòrica:** El valor matemàtic esperat per a cada resultat per poder comparar-lo amb la pràctica.


* **Representació Gràfica:** Inclou un gràfic visual per seguir l'evolució dels resultats i observar com es distribueixen.
* **Enfocament Pedagògic:** Incorpora explicacions Didàctiques ("Sabies que...?") per introduir conceptes com la **Llei dels Grans Nombres**, mostrant com la freqüència relativa s'acosta a la probabilitat teòrica a mesura que augmenta el nombre d'intents (p. ex., 100 o 1.000 repeticions).
* **Historial d'Intents:** Manté un registre dels darrers resultats obtinguts per a una revisió detallada pas a pas.

---

### Objectiu Educatiu

L'eina serveix com un **laboratori virtual de matemàtiques** que permet als estudiants passar de l'experimentació concreta a l'abstracció matemàtica, facilitant la comprensió de la incertesa, la freqüència i el comportament de l'atzar a gran escala.
